# Xabarnoma: yangiliklar sayti (o'quv loyihasi)

Yirik o'zbek yangiliklar portallari uslubidagi sayt maketi. Yangiliklar to'qima, rasmlar picsum.photos'dan olinadi.

Imkoniyatlar: bosh sahifa (asosiy yangilik + kategoriyalar), kategoriya sahifasi, qidiruv, maqola sahifasi, so'nggi va ko'p o'qilgan yangiliklar, valyuta kursi qatori, til tugmalari, tungi rejim, telefonga moslashgan menyu.

## Ishga tushirish
Hech narsa o'rnatish shart emas: `index.html` faylini brauzerda oching.
Yoki serverda: `npx serve .` yoki `python3 -m http.server`, keyin http://localhost:8000 ni oching.

Yangilik qo'shish uchun `data.js` dagi `NEWS` ro'yxatiga yangi element qo'shing.
